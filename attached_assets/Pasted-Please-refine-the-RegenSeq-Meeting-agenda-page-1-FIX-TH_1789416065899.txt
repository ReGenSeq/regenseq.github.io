## 1. FIX THE AGENDA ROW STRUCTURE

The agenda currently places times/durations inconsistently depending on whether an item is a talk, session, or break.

Change this so EVERY agenda item follows the same horizontal alignment system.

On desktop, each row should have three consistent columns:

TIME | EVENT CONTENT | DURATION

For example:

11:45 AM – 12:10 PM | Kunal Pandit / RegenSeq | 25 MIN

12:35 – 1:25 PM | Pizza Lunch & Networking | 50 MIN

3:00 – 4:15 PM | Session 3: Optical Pooled Screens | 75 MIN

Requirements:

* All start/end times must appear in the same left-hand column.
* All durations must appear in the same right-hand column.
* The center content column contains the session/talk/break information.
* Do not move the time or duration to another line simply because the event is a different category.
* Keep column widths consistent across the entire agenda.
* Align all rows to the same grid.
* Session rows may have a different background or typographic hierarchy, but they must still use the same three-column layout.
* Breaks/networking rows may have different styling, but must still use the same three-column layout.
* Individual talks should follow exactly the same grid.

On mobile, collapse gracefully, but preserve a consistent order:
TIME
EVENT
DURATION

Do not let category styling change the basic information layout.
